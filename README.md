# 微信 / QQ 群发 · 定时发送助手

在 Windows 电脑上模拟操作**微信 / QQ 电脑版**，实现**批量群发**和**定时发送**。自用工具，非商业。

## 一、安装（一次性）

电脑已有 Python 3.10，只需装 3 个库。打开命令行（CMD 或 PowerShell），运行：

```bash
pip install pyautogui pyperclip pillow
```

## 二、首次准备（一次性，约 20 分钟）

1. **登录微信 PC 版**（Windows 版微信），保持窗口打开（别最小化到托盘）。
2. **给要群发的对象设备注名**（关键，避免昵称变了搜不到）：
   - 好友：打开聊天 → 点右上角「…」→ 设置备注名，改成固定的名字（如「张三」）。
   - 群聊：点群右上角「…」→ 设置「群备注」（仅自己可见）。
   - 脚本是用**备注名**去搜索的，所以备注名固定后，对方改昵称也不影响。
3. **录入通讯录**：打开本程序，左侧输入框逐个添加这些备注名。

## 三、日常使用（每次 30 秒）

1. 打开要用的**微信或 QQ 电脑版**（先登录、窗口别最小化到托盘）。
2. 运行程序：双击**桌面的「信息发送助手」**，或在 PyCharm 里运行 `main.py`。
3. 窗口里：**顶部选「微信 / QQ」→ 左侧勾选要发的人 → 中间填内容 → 下方填时间（留空=立即）→ 点按钮**。

## 四、三种模式

| 模式 | 勾选人数 | 时间栏 | 操作 |
|------|---------|--------|------|
| 单独定时发送 | 1 人 | 填 HH:MM | 点「定时发送」 |
| 单独群发 | 多人 | 留空 | 点「立即发送」 |
| 定时群发 | 多人 | 填 HH:MM | 点「定时发送」 |

## 五、重要注意事项

- **定时发送期间**：电脑不能睡眠、不能合盖、不能关机（屏幕黑屏无所谓）。笔记本建议插电、不合盖。
- **测试**：第一次先用「文件传输助手」或小号加进通讯录试发，确认无误再正式用。
- **兜底**：脚本搜不到某个名字时，那条会发不出去（不会发错人），并如实记为「失败」，最后日志会列出「失败名单」让你手动补发。
- **封号风险**：批量自动发消息可能触发微信/QQ 风控。低频、小批量、自用 → 风险低但不为零。
- **QQ 平台**：已可用。QQ 没有可靠的搜索快捷键，脚本改用「点顶部搜索框」实现；发送时请保持 QQ 窗口不被其他窗口遮挡（脚本会自动把 QQ 置前）。

## 六、任务管理（任务区在右侧）

点「立即发送 / 定时发送」后，右侧会出现一条任务，实时显示状态和进度：

| 按钮 | 作用 |
|------|------|
| 暂停/继续 | 暂停当前任务（不删除），再点继续 |
| 载入编辑 | 把任务的内容/名单/时间填回编辑区，改完重新发 |
| 删除任务 | 中途也能直接删掉，立即停止 |

- 状态有：`进行中 / 已暂停 / 等待定时 / 完成 / 已取消`。
- 不再用「鼠标甩左上角」中断了，统一靠上面这三个按钮。

## 七、耗时说明（定时群发前必看）

每条消息要「搜索 → 进会话 → 粘贴 → 发送 → 检测」，微信本身响应就要 1~2 秒，**约 4 秒/人**：

- 发 10 人 ≈ 40 秒；发 30 人 ≈ 2 分钟。
- 「定时发送」是**到点开始发**，几十人是连续发完，不是卡在那一分钟。
- 顶部「每条间隔(秒)」默认 1.5，可调小加快，但太小时微信可能来不及响应导致失败。

## 八、常见问题

- **点发送没反应**：确认微信窗口已打开、未最小化到托盘；确认已 `pip install` 依赖。
- **搜不到人**：检查备注名是否和通讯录里录的一致；检查是否用「备注名」而非昵称。
- **中文粘贴不出**：程序走的是剪贴板粘贴，若失败重开程序再试。
- **微信版本更新后失效**：快捷键可能变化，联系我调整脚本。
